# Dice Simulator 🎲
A simple Java program that simulates rolling one or two dice using randomly generated numbers.

## Features
- Choose to roll one or two dice
- Generate random dice values from 1 to 6
- Calculate the total when rolling two dice
- Roll again as many times as desired

## Technologies Used
- Java
- Scanner class
- Random class
- Do-while loop
- If-else statements

## How to Run
1. Download DiceSimulator.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac DiceSimulator.java
   
4. Run the program:
   java DiceSimulator

## Example Output
How many dice do you want to roll (1/2):
2
You rolled 4 on the first die!
You rolled 3 on the second die!

## Purpose
This project was created to practise Java basics, random number generation, loops, user input, and conditional statements.
